# Базовые определения ООП

## Базовые определения

> [!tip] Простыми словами: Это словарь главных слов ООП: что такое класс, объект, поле, свойство, метод и конструктор.
### Класс

> [!tip] Простыми словами: Класс — это чертёж: он описывает, какие данные и действия будут у будущих объектов.

> [!definition]
> Класс --- универсальный комплексный тип данных, описывающий характеристики и поведения некоторой сущности. В классе тематически объединяются данные и действия над ними.

```csharp
public class Person
{
}
```

Тут class сообщает, что объявляется класс. 
Person -- имя класса; 
внутри фигурных скобок находятся элементы класса

> [!definition]
> Объект --- это конкретный экземпляр класса.

```csharp
Person person = new Person();
```

Person person, где Person -- тип переменной, а person -- имя переменной. 
new Person(), где new создает новый объект класса, а Person() вызывает конструктор класса. 

В результате person позволяет обращаться к созданному объекту.

Можно создать несколько объектов одного класса:

```csharp
Person firstPerson = new Person();
Person secondPerson = new Person();
```

Оба объекта созданы по одному описанию, но могут содержать разные данные.

### Поле

> [!tip] Простыми словами: Поле — это внутренняя переменная объекта, где он хранит своё состояние.

Ну вообще-то, Поле — это множество (F), на котором заданы две бинарные операции: сложение (обычно обозначается (+)) и умножение (обозначается (cdot )), такие что выполняются следующие условия: 
-- Множество (F) является коммутативной (абелевой) группой по сложению. 
-- Существует нейтральный элемент по сложению (нуль, (0)), такой что (a + 0 = a) для всех (a in F). 
-- Для каждого элемента (a) существует противоположный элемент (-a), такой что (a + (-a) = 0). 
-- Множество всех ненулевых элементов (F setminus {0}) является коммутативной группой по умножению. 
-- Существует нейтральный элемент по умножению (единица, (1)), такой что (a cdot 1 = a) для всех (a in F). 
-- Для каждого элемента (a ne 0) существует обратный элемент (a^{-1}), такой что (a cdot a^{-1} = 1) 
-- Умножение дистрибутивно относительно сложения:(a cdot (b + c) = a cdot b + a cdot c) 
Извините, вернемся к проге.

> [!definition]
> Поле — это переменная, объявленная внутри класса и предназначенная для хранения состояния объекта.

Поле хранит данные, составляющие состояние объекта.

```csharp
public class Person
    {
         private int _age
    }
```

Здесь:

- int — тип поля;
- _age — имя поля;
- private — поле доступно только внутри класса Person.

Для каждого объекта класса создаётся собственное значение обычного поля:

```csharp
Person firstPerson = new Person();
Person secondPerson = new Person();
```

У firstPerson и secondPerson будут отдельные значения _age.

Поля не обязаны быть private:

```csharp
public int age;
```

Но общедоступные поля обычно нежелательны, потому что внешний код сможет бесконтрольно изменять их значения.
Обычно, если поле private, то его название начинается с нижнего подчеркивания (_)

итог:
Поле — это переменная класса, предназначенная для хранения данных объекта. Поля обычно делают закрытыми, чтобы внешний код не изменял состояние объекта напрямую.

### Свойство

> [!tip] Простыми словами: Свойство — это аккуратная дверца к данным: снаружи выглядит как переменная, а внутри может проверять или вычислять значение.

> [!definition]
> свойство — это элемент класса, предоставляющий доступ к данным и внешне имитирующий переменную.

Внутри свойства используются аксессоры:

- get — получение значения;
- set — присваивание нового значения;
- init — задание значения только при создании объекта.

Пример свойства, связанного с полем:

```csharp
public class Person
{
    private int _age = 18;
    public int Age
    {
        get
        {
            return _age;
        }
        set
        {
            _age = value;
        }
    }
}
```

Чтение: int currentAge = person.Age;

При этом выполняется get.

Запись: person.Age = 20;

При этом выполняется set, а присваиваемое значение доступно через специальное слово value.

#### Контролируемое свойство

```csharp
public int Age
{
    get
    {
        return _age;
    }
    set
    {
        if (value >= 0 && value <= 150)
        {
            _age = value;
        }
    }
}
```

Теперь нельзя записать некорректный возраст: person.Age = -100;

Условие не выполнится, поэтому поле _age не изменится.

Тут используется вариант, который принудительно помещает значение в диапазон от 0 до 150:

```csharp
public int Age
{
    get => _age;
    set => _age = Math.Max(Math.Min(value, 150), 0);
}
```

Если передать -100, будет записан 0. Если передать 500, будет записано 150.

#### Автореализуемое свойство

```csharp
public string Name { get; set; } = "Иван Иванов";
```

Здесь поле явно не объявлено. Компилятор создаёт скрытое поле самостоятельно.

#### Свойство с ограниченной записью

```csharp
public string Name { get; private set; } = "Иван Иванов";
```

- прочитать Name можно извне класса;
- изменить Name напрямую извне нельзя;
- внутри класса изменение разрешено.

#### Свойство только для чтения

```csharp
public string PersonData
{
    get => Name + ". Возраст: " + Age;
}
```

Оно не обязательно непосредственно хранит данные. Значение может вычисляться на основании других данных.

### Различие поля и свойства

> [!tip] Простыми словами: Поле хранит значение напрямую, а свойство решает, как это значение читать или менять.

```csharp
private int _age; // поле
public int Age    // свойство
{
    get => _age;
    set => _age = value;
}
```

Поле _age непосредственно хранит значение.

Свойство Age организует доступ к этому значению.

**Итог**
Поле является переменной класса и непосредственно хранит данные. Свойство предоставляет доступ к данным через аксессоры get, set или init. В свойстве можно проверить значение, вычислить его или ограничить доступ к записи.

### Метод

> [!tip] Простыми словами: Метод — это действие, которое объект умеет выполнять.

> [!definition]
> Метод — это функция, объявленная внутри класса и описывающая действие или поведение объекта.

```csharp
public void PrintInformation()
{
    Console.WriteLine("Информация о человеке");
}
```

Разбор:

- public — метод можно вызвать из внешнего кода;
- void — метод не возвращает результат;
- PrintInformation — имя метода;
- () — список параметров, сейчас он пустой;
- внутри фигурных скобок находится тело метода.

Вызов:
person.PrintInformation();

#### Метод с параметром

```csharp
public void ChangeAge(int newAge)
{
    Age = newAge;
}
```

newAge — параметр метода.

Вызов:person.ChangeAge(25);

Число 25, переданное при вызове, называется аргументом.

#### Метод с возвращаемым значением

```csharp
public string GetInformation()
{
    return Name + ". Возраст: " + Age;
}
```

Перед именем указан тип string, поэтому метод должен вернуть строку: string information = person.GetInformation();

Короткая запись

```csharp
public string GetInformation() => Name + ". Возраст: " + Age;
```

Она означает то же самое, что и предыдущий вариант.

**Итог**
Метод — это функция класса, описывающая действие объекта. Метод может принимать параметры, выполнять операции и возвращать результат указанного типа. Если результат не возвращается, используется тип void.

### Конструктор

> [!tip] Простыми словами: Конструктор — это запуск объекта: он срабатывает при `new` и задаёт начальные значения.

> [!definition]
> Конструктор — специальный метод класса, который автоматически вызывается при создании объекта через new и инициализирует его состояние. Его имя совпадает с именем класса, и у него нет возвращаемого типа. Обычный метод вызывается явно, описывает действие и может возвращать результат.

Особенности конструктора:

- его имя совпадает с именем класса;
- у него нет возвращаемого типа;
- перед ним не пишут даже void;
- он вызывается при использовании new.

```csharp
public class Person
{
    public Person()
    {
    }
}
```

Это конструктор без параметров.

Создание объекта: Person person = new Person();

Здесь Person() — вызов конструктора.

#### Конструктор с параметрами

```csharp
public class Person
{
    private int _age;
    public string Name { get; private set; }
    public int Age
    {
        get => _age;
        set => _age = Math.Max(Math.Min(value, 150), 0);
    }
    public Person(string name, int age)
    {
        Name = name;
        Age = age;
    }
}
```

Создание объекта: Person person = new Person("Анна", 20);

Во время создания:

1. выделяется память под объект;
2. поля получают начальные значения; 
3. вызывается конструктор;
4. Name получает значение "Анна";
5. свойству Age передаётся 20;
6. свойство проверяет значение;
7. создаётся готовый объект.
Почему присваиваем значение свойству, а не полю Age = age?
Так мы используем проверку, находящуюся в свойстве Age.

Если написать: _age = age, то проверка свойства будет обойдена.

#### this

```csharp
public Person(string name)
{
    this.Name = name;
}
```

this обозначает текущий объект, для которого выполняется код.

Особенно полезно при совпадении имён:

```csharp
private string _name;
public Person(string name)
{
    _name = name;
}
```

Или без подчёркивания:

```csharp
private string _name;
public Person(string name)
{
    this.name = name;
}
```

* this.name — поле текущего объекта; 
* name — параметр конструктора.

#### Конструктор по умолчанию

Если программист не написал ни одного конструктора, компилятор создаёт конструктор без параметров автоматически.

```csharp
public class Person
{
}
```

Поэтому допустимо: Person person = new Person();

Но если написать собственный конструктор:

```csharp
public Person(string name)
{
    Name = name;
}
```

То автоматический конструктор без параметров больше не добавляется, тогда код не скомпилируется: Person person = new Person();

Чтобы оба варианта работали, нужно явно объявить оба конструктора:

```csharp
public Person()
{
}
public Person(string name)
{
    Name = name;
}
```

Это называется **перегрузкой конструкторов**.

**Итог**
Конструктор — это специальный метод, который вызывается при создании объекта и инициализирует его состояние. Его имя совпадает с именем класса, и он не имеет возвращаемого типа. В классе может быть несколько конструкторов с разными параметрами.

### Цельный пример

> [!tip] Простыми словами: Здесь все базовые элементы собраны в одном классе `Person`, чтобы было видно, как они работают вместе.
```csharp
public class Person
{
    // Поле: непосредственно хранит возраст 
    private int _age = 18; 
    // Автореализуемое свойство
    public string Name { get; private set; } 
    // Свойство с проверкой 
    public int Age
    { 
        get => _age; 
        set => _age = Math.Max(Math.Min(value, 150), 0); 
    }
    // Вычисляемое свойство только для чтения
    public string PersonData 
    { 
        get => Name + ". Возраст: " + Age; 
    } 
    // Конструктор без параметров 
    public Person() 
    {
        Name = "Неизвестно"; 
    }
    // Конструктор с параметрами 
    public Person(string name, int age)
    { 
        Name = name; 
        Age = age; 
    } 
    // Метод без возвращаемого значения 
    public void PrintInformation() 
    { 
        Console.WriteLine(PersonData); 
    } 
    // Метод с возвращаемым значением
    public bool IsAdult() 
    { 
        return Age >= 18; 
    } 
    }
```
Использование:

- Person firstPerson = new Person();
- Person secondPerson = new Person("Анна", 20);
- secondPerson.PrintInformation();
- bool isAdult = secondPerson.IsAdult();
- Console.WriteLine(isAdult);

**Итог**

Person — это класс, описывающий человека. firstPerson и secondPerson — объекты этого класса. 
Поле _age хранит возраст и закрыто модификатором private. 
Свойство Age предоставляет контролируемый доступ к полю и ограничивает значение диапазоном от 0 до 150. 
Name является автореализуемым свойством с закрытым set, поэтому изменить имя извне класса нельзя. 
Конструкторы задают начальное состояние объектов. 
Метод PrintInformation выводит данные, а метод IsAdult возвращает результат проверки возраста.
