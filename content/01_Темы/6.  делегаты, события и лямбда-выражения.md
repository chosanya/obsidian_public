# Делегаты, события и лямбда-выражения

## Делегат

> [!tip] Простыми словами: Делегат — это переменная, в которую можно положить метод.

Делегат — тип, который хранит ссылку на метод с определённой сигнатурой.

```csharp
Action action = PrintMessage;
action();

void PrintMessage()
{
    Console.WriteLine("Привет");
}
```

Здесь Action хранит ссылку на метод без параметров и без возвращаемого значения.

## Лямбда-выражение

> [!tip] Простыми словами: Лямбда — это короткий способ написать маленькую функцию прямо на месте.

Лямбда-выражение — короткая запись анонимной функции.

```csharp
Action action = () => Console.WriteLine("Привет");
```

В RelayCommand часто встречается:

```csharp
CalculateCommand = new RelayCommand(() => Calculate());
```

То есть в команду передаётся действие, которое нужно выполнить.

Если действие асинхронное, лямбда может быть `async`:

```csharp
CalculateCommand = new RelayCommand(async () => await CalculateAsync());
```

> [!tip] Простыми словами: это всё ещё “передай действие в команду”, просто действие умеет ждать через `await`.

## Событие

> [!tip] Простыми словами: Событие — это сигнал для подписчиков: что-то произошло, можно реагировать.

Событие — механизм уведомления других объектов о том, что что-то произошло.

```csharp
public event EventHandler? Completed;
```

Вызов события:

```csharp
Completed?.Invoke(this, EventArgs.Empty);
```

В ICommand событие:

```csharp
CanExecuteChanged
```

сообщает интерфейсу, что возможность выполнения команды изменилась.

**пример**

```csharp
CalculateCommand = new RelayCommand(() => Calculate());
```

1. Создаётся новый объект `RelayCommand`.
2. В его конструктор передаётся действие: вызвать метод `Calculate`.
3. Полученная команда сохраняется в свойство `CalculateCommand`.
4. Когда интерфейс вызовет команду, `RelayCommand` выполнит переданное действие, то есть метод `Calculate()`.

На экзамене: Здесь создаётся объект команды `RelayCommand`. В конструктор передаётся лямбда-выражение, которое вызывает метод `Calculate`. При выполнении команды будет запущен этот метод.


## Итог

> [!tip] Простыми словами: Делегат хранит действие, лямбда коротко его описывает, событие сообщает о произошедшем.

Делегат хранит ссылку на метод. Лямбда-выражение позволяет кратко описать передаваемый код. Событие уведомляет подписчиков о произошедшем действии.
