# Абстрактный класс

> [!tip] Простыми словами: Абстрактный класс — основа для похожих классов, но сам по себе объектом не становится.

### Абстрактный класс

Абстрактный класс объявляется через abstract:

```csharp
public abstract class Animal
{
    public string Name { get; set; }
    public void Eat()
    {
        Console.WriteLine("{Name} ест");
    }
    public abstract void MakeSound();
}
```

Здесь: public abstract class Animal, означает, что Animal — абстрактный класс.

Из него нельзя напрямую создать объект: Animal animal = new Animal(); // ошибка

Абстрактный класс **предназначен** для наследования.

Внутри него могут быть обычные элементы с готовой реализацией:

```csharp
public void Eat()
{
    Console.WriteLine("{Name} ест");
}
```

А также абстрактные методы: public abstract void MakeSound();

> [!definition]
> Абстрактный метод:
> 
> - не имеет тела;
> - задаёт обязательную операцию;
> - должен быть реализован в производном классе через override.

Производный класс:

```csharp
public class Dog : Animal
{
    public override void MakeSound()
    {
        Console.WriteLine("Гав");
    }
}

Теперь объект создать можно:
-- Dog dog = new Dog();
-- dog.Name = "Шарик";
-- dog.Eat();
-- dog.MakeSound();

Результат:

Шарик ест

Гав
```

Класс Dog получил готовый метод Eat() и самостоятельно реализовал обязательный метод MakeSound().

Если Dog не реализует абстрактный метод, он тоже должен быть объявлен абстрактным.

#### Когда нужен абстрактный класс

Когда классы действительно являются родственными сущностями и имеют общее состояние или реализацию.

Например:
-- Animal → Dog, Cat; 
-- Shape → Circle, Rectangle; 
-- Employee → Manager, Programmer.

Можно вынести общее состояние:

```csharp
public abstract class Shape
{
    public string Name { get; set; }
    public abstract double CalculateArea();
    public void PrintName()
    {
        Console.WriteLine(Name);
    }
}
```

Производный класс:

```csharp
public class Circle : Shape
{
    public double Radius { get; set; }
    public override double CalculateArea()
    {
        return Math.PI * Radius * Radius;
    }
}
```
