# Интерфейс класса

> [!tip] Простыми словами: Интерфейс класса — это видимая снаружи часть объекта: что можно вызвать или прочитать.

### Интерфейс класса

В данном случае под интерфейсом понимается не обязательно конструкция interface из C#.

> [!definition]
> Интерфейс объекта — это совокупность доступных извне элементов класса.

Например:

```csharp
public decimal Balance
public void Deposit(decimal amount)
public bool Withdraw(decimal amount)
```

Это публичный интерфейс класса BankAccount.
Поле private decimal _balance является внутренней деталью реализации.
Таким образом, инкапсуляция — не просто private

**Частая ошибка:**
"Инкапсуляция — это когда всё сделано private" -- Это неполный ответ.

private является одним из инструментов инкапсуляции. Но сама инкапсуляция шире:

- объединение данных и методов в классе;
- сокрытие внутренней реализации;
- предоставление контролируемого доступа;
- защита объекта от некорректного состояния.

Например, этот класс использует private, но почти не управляет состоянием:

```csharp
public class Person
{
    private int _age;
    public void SetAge(int age)
    {
        _age = age;
    }
}
```

Метод позволяет записать отрицательный возраст. Формально поле скрыто, но контроль состояния реализован плохо.

Лучше:

```csharp
public class Person
{
    private int _age;
    public int Age
    {
        get => _age;
        set
        {
            if (value >= 0 && value <= 150)
            {
                _age = value;
            }
        }
    }
}
```

Теперь класс контролирует допустимые значения.
