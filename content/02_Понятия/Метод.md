# Метод

> [!tip] Простыми словами: Метод — действие или функция, которая принадлежит классу.

### Метод

> [!definition]
> Метод — это функция, объявленная внутри класса и описывающая действие или поведение объекта.

```csharp
public void PrintInformation()
{
    Console.WriteLine("Информация о человеке");
}
```

Разбор:

- public — метод можно вызвать из внешнего кода;
- void — метод не возвращает результат;
- PrintInformation — имя метода;
- () — список параметров, сейчас он пустой;
- внутри фигурных скобок находится тело метода.

Вызов:
person.PrintInformation();

#### Метод с параметром

```csharp
public void ChangeAge(int newAge)
{
    Age = newAge;
}
```

newAge — параметр метода.

Вызов:person.ChangeAge(25);

Число 25, переданное при вызове, называется аргументом.

#### Метод с возвращаемым значением

```csharp
public string GetInformation()
{
    return Name + ". Возраст: " + Age;
}
```

Перед именем указан тип string, поэтому метод должен вернуть строку: string information = person.GetInformation();

Короткая запись

```csharp
public string GetInformation() => Name + ". Возраст: " + Age;
```

Она означает то же самое, что и предыдущий вариант.

**Итог**
Метод — это функция класса, описывающая действие объекта. Метод может принимать параметры, выполнять операции и возвращать результат указанного типа. Если результат не возвращается, используется тип void.
