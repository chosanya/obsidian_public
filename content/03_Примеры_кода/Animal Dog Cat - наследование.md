# Animal Dog Cat - наследование

> [!tip] Простыми словами: Пример показывает, как общие возможности выносятся в `Animal`, а `Dog` и `Cat` добавляют своё.

## Наследование

> [!definition]
> Наследование — это принцип ООП, позволяющий описать новый класс на основе существующего, частично или полностью заимствуя его функциональность.

Проще: Наследование позволяет создать новый класс, который получает общие элементы существующего класса и добавляет или изменяет собственное поведение.

Класс, от которого наследуются, называется:

- базовым;
- родительским;
- суперклассом.

Класс, который наследуется, называется:

- производным;
- дочерним;
- наследником;
- потомком.

Пример

**Это базовый класс.**

```csharp
public class Animal
{
    public string Name { get; set; }
    public void Eat()
    {
        Console.WriteLine("{Name} ест");
    }
}
```

**Это дочерний класс.**

```csharp
public class Dog : Animal
{
    public void Bark()
    {
        Console.WriteLine("{Name} лает");
    }
}
```

Запись "Dog : Animal" означает, что Класс Dog наследуется от класса Animal.

Создание объекта: 
Dog dog = new Dog(); 
dog.Name = "Шарик"; 
dog.Eat(); 
dog.Bark(); 
Объект dog может использовать: Name, Eat(), потому что они определены в базовом классе Animal.

Также он может использовать: Bark(), потому что этот метод добавлен в классе Dog.

Что наследуется

Производный класс получает доступные ему:

- поля;
- свойства;
- методы;
- события.

Но важное правило:
**Конструкторы не наследуются.**

То есть конструктор Animal не становится конструктором Dog.

### Конструкторы при наследовании

```csharp
public class Animal
{
    public string Name { get; }
    public Animal(string name)
    {
        Name = name;
    }
}
```

**Производный класс:**

```csharp
public class Dog : Animal
{
    public Dog(string name) : base(name)
    {
    }
}
```

Здесь: base(name) вызывает конструктор базового класса Animal.

Создание: "Dog dog = new Dog("Шарик");"

Порядок: 
1. вызывается конструктор Dog; 
2. перед выполнением его тела вызывается конструктор Animal; 
3. базовый класс задаёт Name; 
4. затем выполняется тело конструктора Dog. 
При создании объекта производного класса конструктор базового класса выполняется первым.

### protected
Иногда потомку нужно иметь доступ к внутреннему элементу базового класса:

```csharp
public class Animal
{
    protected int Age;
}
```

Поле Age доступно внутри Animal и внутри классов-наследников. Но недоступно из обычного внешнего кода: 
Dog dog = new Dog(); 
dog.Age = 5; // ошибка 
Сравнение:

- private — только внутри самого класса;
- protected — внутри класса и его наследников;
- public — доступно извне.

### Зачем нужно наследование
Без наследования пришлось бы повторять код:

```csharp
public class Dog
{
    public string Name { get; set; }
    public void Eat()
    {
    }
}
public class Cat
{
    public string Name { get; set; }
    public void Eat()
    {
    }
}
```

С наследованием общая часть выносится в Animal:

```csharp
public class Animal
{
    public string Name { get; set; }
    public void Eat()
    {
    }
}
public class Dog : Animal
{
    public void Bark()
    {
    }
}
public class Cat : Animal
{
    public void Meow()
    {
    }
}
```

Это уменьшает дублирование и создаёт иерархию классов.

### Ограничения в C#
Класс может непосредственно наследоваться только от одного класса: public class Dog : Animal

Так нельзя: public class Dog : Animal, Pet, если Animal и Pet являются классами.

При этом класс может реализовывать несколько интерфейсов — это разберём отдельно.

Класс с модификатором **sealed** запрещает наследование:

```csharp
public sealed class FinalClass
{
}
```

От него нельзя создать класс-потомок.

**Итог**

Наследование — это принцип ООП, при котором новый класс создаётся на основе существующего и получает его доступные поля, свойства и методы. Исходный класс называется базовым, а новый — производным. Производный класс может добавлять новые элементы или изменять унаследованное поведение. Конструкторы не наследуются, но при создании потомка сначала вызывается конструктор базового класса.
