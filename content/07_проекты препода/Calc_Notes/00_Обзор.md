# Calc

## Что делает проект

`Calc` — WPF-калькулятор с сеткой кнопок и переключением темы оформления.

В текущем коде реально реализованы:

- ввод цифр;
- смена знака `±`;
- ввод дробной части через `.` в `Tag`;
- переключение тем через `ResourceDictionary`.

Кнопки операций `+`, `-`, `×`, `÷`, `=`, `sqrt`, `1/x`, `C` в XAML есть, но не все имеют обработчики.

## Основные технологии

- C#.
- .NET 10.0 Windows.
- WPF.
- XAML.
- `ResourceDictionary`.
- `Style`.
- `DynamicResource`.
- обработчики событий.

## Архитектура

Это WPF без MVVM.

```text

→ MainWindow.xaml
→ MainWindow.xaml.cs
→ GreenBlueTheme.xaml / OtherTheme.xaml
```

