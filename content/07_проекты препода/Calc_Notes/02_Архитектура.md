# Архитектура Calc

## Общая идея

Окно калькулятора описано в XAML. Логика ввода цифр и смены темы находится в code-behind.

## Схема

```mermaid
flowchart TD
    App["App.xaml"] --> Window["MainWindow.xaml"]
    Window --> MainWindowClass["MainWindow.xaml.cs"]
    MainWindowClass --> Digit["Digit_Click"]
    MainWindowClass --> Theme["ThemeSelector_SelectionChanged"]
    Theme --> Green["GreenBlueTheme.xaml"]
    Theme --> Other["OtherTheme.xaml"]
```

## Почему это не MVVM

Нет `ViewModel`, `DataContext`, `Binding` к ViewModel и `ICommand`. События кнопок напрямую вызывают методы окна.

## Главная особенность

Темы подключаются динамически:

```csharp
Application.Current.Resources.MergedDictionaries.Add(resourceDictionary);
```
