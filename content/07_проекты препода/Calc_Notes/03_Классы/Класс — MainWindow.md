# Класс — MainWindow

## Исходный файл

`Calc/MainWindow.xaml.cs`

## Назначение класса

`MainWindow` — главное окно калькулятора. Оно хранит текущее введенное число и реагирует на нажатия цифровых кнопок и смену темы.

## Поля

```csharp
private double _c = 0.0;
private int _d = 0;
```

`_c` хранит текущее число. `_d` используется для ввода дробной части.

## Конструктор

Создает список тем, назначает его `ThemeSelector.ItemsSource` и выбирает первую тему.

## Обработчики

- `Clear_Click` — показывает сообщение, но в XAML не привязан к кнопке `C`.
- `Digit_Click` — обрабатывает цифры, `pm` и `.`.
- `ThemeSelector_SelectionChanged` — загружает выбранный `ResourceDictionary`.

## Что сказать на экзамене

Класс показывает code-behind подход в WPF: элементы XAML имеют имена, а события связаны с методами окна.
