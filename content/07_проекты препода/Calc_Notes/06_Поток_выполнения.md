# Поток выполнения Calc

## Общая схема

```text
App.xaml
→ MainWindow.xaml
→ MainWindow()
→ InitializeComponent()
→ заполнение ThemeSelector
→ выбор темы
→ Digit_Click / ThemeSelector_SelectionChanged
```

## Пошагово

1. WPF запускает `App`.
2. Через `StartupUri` открывается `MainWindow`.
3. Конструктор вызывает `InitializeComponent`.
4. В `ThemeSelector` записывается список тем.
5. Выбирается первая тема.
6. При нажатии цифровой кнопки вызывается `Digit_Click`.
7. При смене темы вызывается `ThemeSelector_SelectionChanged`.
8. Словарь ресурсов очищается и заменяется выбранной темой.

## Факт проверки

На текущей macOS-среде сборка завершилась ошибкой `NETSDK1100`, потому что проект таргетит `net10.0-windows`. Исходный код не менялся.
