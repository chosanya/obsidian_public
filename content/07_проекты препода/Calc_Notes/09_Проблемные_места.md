# Проблемные места Calc

## Не все кнопки имеют обработчики

Кнопки операций есть в XAML, но обработчики назначены не всем.

Например, `+`, `-`, `×`, `÷`, `=` не имеют логики вычисления.

## `Clear_Click` не привязан в XAML

Метод есть, но кнопка `C` не имеет `Click="Clear_Click"`.

## Возможен `NullReferenceException`

```csharp
var style = ThemeSelector.SelectedItem as string;
var uri = new Uri(style + ".xaml", UriKind.Relative);
```

Если `SelectedItem` будет `null`, путь будет некорректным.

## `Double.Parse(btn.Tag.ToString())`

Если обработчик попадет на кнопку с нечисловым `Tag`, будет ошибка. Сейчас обработчик назначен только цифрам, `pm` и `.`, но это важно понимать.

## Сборка на macOS

Проверка завершилась ошибкой `NETSDK1100`, потому что проект WPF таргетит Windows.
