# CanvasDrawing

## Что делает проект

`CanvasDrawing` — WPF/MVVM-проект для динамического отображения точек на `Canvas` при движении мыши.

ViewModel хранит коллекцию видимых точек `VisiblePoints` и команду `MouseMoveCommand`, которая добавляет новую точку и ограничивает количество точек до 60.

На Windows:

```bash
dotnet run --project CanvasDrawing/CanvasDrawing.csproj
```

В текущей macOS-среде проект не собирается из-за `NETSDK1100`, потому что таргетит `net10.0-windows`.
