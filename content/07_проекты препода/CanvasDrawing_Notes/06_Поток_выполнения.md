# Поток выполнения CanvasDrawing

## Ожидаемая схема

```text
App.xaml
→ MainWindow
→ DataContext = MainViewModel
→ MouseMove
→ MouseMoveCommand
→ OnMouseMove
→ VisiblePoints.Add
→ ItemsControl обновляет Canvas
```

## Фактический нюанс

В коде есть `MouseMoveCommand`, но в `MainWindow.xaml` не видно привязки события `MouseMove` к этой команде.

## Факт проверки

На текущей macOS-среде сборка завершилась ошибкой `NETSDK1100`, потому что проект таргетит `net10.0-windows`.
