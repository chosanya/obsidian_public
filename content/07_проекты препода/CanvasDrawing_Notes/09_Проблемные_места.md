# Проблемные места CanvasDrawing

## Нет привязки события мыши к команде

В ViewModel есть:

```csharp
public ICommand MouseMoveCommand { get; }
```

Но в `MainWindow.xaml` не видно `MouseMove`, `Interaction.Triggers` или другой связи с командой.

## Две реализации RelayCommand

В проекте есть локальный `RelayCommand`, но ViewModel использует generic `RelayCommand<MouseEventArgs>` из MVVM Light.

## `OnPropertyChanged` почти не используется

Коллекция `VisiblePoints` сама уведомляет UI, поэтому событие `PropertyChanged` в текущем коде почти не задействовано.

## Сборка на macOS

Проверка завершилась `NETSDK1100`, потому что проект WPF таргетит Windows.
