# Enumarations

## Что делает проект

Проект демонстрирует перечисляемые последовательности в C#: классы, которые можно обходить через `foreach`.

В коде есть несколько последовательностей:

- `Fibo` — числа Фибоначчи через `yield return`;
- `PrimeNum` — простые числа до 100 через `yield return`;
- `Odd` — нечетные числа через отдельный класс-перечислитель `OddEnumerator`.

## Основные технологии

- C#.
- .NET 9.0.
- Консольное приложение.
- `IEnumerable<T>`.
- `IEnumerator<T>`.
- `yield return`.

## Архитектура

Архитектура учебная: весь код находится в `Program.cs`.

Основная идея:

```text
foreach
→ IEnumerable<T>.GetEnumerator()
→ IEnumerator<T> или yield-машина
→ последовательная выдача элементов
```

## Как запустить

```bash
dotnet run --project Enumarations/Enumarations.csproj
```

## Что важно понять перед разбором

`foreach` работает не магически. Он требует, чтобы объект предоставил перечислитель. Для этого класс обычно реализует `IEnumerable<T>` и метод `GetEnumerator`.

`yield return` позволяет не писать отдельный класс `IEnumerator<T>` вручную: компилятор создает его сам.
