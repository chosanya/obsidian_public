# Класс — Odd

## Исходный файл

`Enumarations/Program.cs`

## Назначение класса

`Odd` представляет последовательность нечетных чисел.

## Поля

```csharp
private IEnumerator<int> _oddEnumerator = new OddEnumerator(3, 20);
```

Поле хранит объект перечислителя.

## Интерфейсы

```csharp
class Odd : IEnumerable<int>
```

Класс можно использовать в `foreach`.

## Методы

```csharp
public IEnumerator<int> GetEnumerator()
{
    return _oddEnumerator;
}
```

Метод возвращает заранее созданный перечислитель.

## Связи

- Использует: [[Класс — OddEnumerator]].
- Демонстрирует: `IEnumerable<int>`.

## Что сказать на экзамене

`Odd` отделяет саму последовательность от механизма обхода. Последовательность реализует `IEnumerable<int>`, а перебор конкретных значений выполняет `OddEnumerator`.

## Проблемное место

`Odd` хранит один экземпляр перечислителя. При повторном обходе состояние может зависеть от того, был ли перечислитель сброшен. В более надежной реализации `GetEnumerator` обычно создает новый перечислитель.
