# Класс — PrimeNum

## Исходный файл

`Enumarations/Program.cs`

## Назначение класса

`PrimeNum` задает последовательность простых чисел от 2 до 99.

## Интерфейсы

```csharp
class PrimeNum : IEnumerable<int>
```

Класс реализует `IEnumerable<int>`, поэтому его можно обходить через `foreach`.

## Методы

```csharp
public IEnumerator<int> GetEnumerator()
```

Перебирает числа от 2 до 99 и возвращает только простые.

```csharp
private bool IsPrime(int a)
```

Проверяет, является ли число простым.

## Фрагмент кода

```csharp
for (int i = 2; i < 100; i++)
{
    if (IsPrime(i)) yield return i;
}
```

## Какие темы используются

- `IEnumerable<int>`;
- `yield return`;
- приватный метод;
- цикл;
- условие;
- алгоритм проверки простоты.

## Что сказать на экзамене

`PrimeNum` показывает ленивую генерацию последовательности: простые числа не сохраняются заранее в массиве, а выдаются по одному во время обхода.
