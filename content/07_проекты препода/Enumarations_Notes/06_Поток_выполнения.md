# Поток выполнения Enumarations

## Общая схема

```text
Program.cs
→ new Fibo()
→ foreach по Fibo
→ new PrimeNum()
→ foreach по PrimeNum
→ завершение
```

## Пошагово

1. Подключаются `System.Collections` и пространство имен `Lesson`.
2. Создается объект `Fibo`.
3. `foreach` вызывает `Fibo.GetEnumerator`.
4. Значения Фибоначчи выдаются через `yield return`.
5. Создается объект `PrimeNum`.
6. `foreach` вызывает `PrimeNum.GetEnumerator`.
7. Цикл перебирает числа от 2 до 99.
8. `IsPrime` проверяет число.
9. Простые числа выдаются через `yield return`.
10. Программа завершается.

## Где находится `Odd`

Классы `Odd` и `OddEnumerator` объявлены, но в активном коде не используются.

## Важное отличие от WPF-проектов

Это консольное приложение. Здесь нет `App`, `MainWindow`, `DataContext`, команд и обновления UI.
