# Проблемные места Enumarations

## Название проекта написано нестандартно

`Enumarations` похоже на опечатку от `Enumerations`. Код не исправляем, но на защите лучше использовать правильный термин: enumeration, enumerable, enumerator.

## `Odd` объявлен, но не используется

В активном коде создаются `Fibo` и `PrimeNum`, но `Odd` не обходится через `foreach`.

## `Odd` хранит один перечислитель

```csharp
private IEnumerator<int> _oddEnumerator = new OddEnumerator(3, 20);
```

Обычно `GetEnumerator` должен возвращать новый перечислитель, чтобы повторные обходы были независимыми.

## Условие в `MoveNext`

```csharp
return _current < _max;
```

При таком условии верхняя граница не включается. Это может быть намеренно, но нужно уметь объяснить.

## `Reset` в современных перечислителях используется редко

Метод требуется интерфейсом, но многие реальные перечислители его не поддерживают или выбрасывают `NotSupportedException`.
