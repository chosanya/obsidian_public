# Enumerable

## Что делает проект

Проект демонстрирует создание собственных перечисляемых последовательностей в C# и повторный обход этих последовательностей через `foreach`.

В проекте есть:

- `Fibonacci` — последовательность чисел Фибоначчи через `yield return`;
- `Even` — последовательность четных чисел через `yield return`;
- `Odd` — последовательность нечетных чисел через ручной `OddEnumerator`.

## Основные технологии

- C#.
- .NET 9.0.
- Консольное приложение.
- `IEnumerable<T>`.
- `IEnumerator<T>`.
- `yield return`.
- `yield break`.

## Архитектура

В проекте есть файл `Program.cs`, но он фактически пустой. Основной код и классы находятся в `Odd.cs`.

```text
Odd.cs
→ top-level демонстрация foreach
→ namespace Enumerable
   ├── Fibonacci : IEnumerable<long>
   ├── Even : IEnumerable<int>
   ├── Odd : IEnumerable<int>
   └── OddEnumerator : IEnumerator<int>
```

## Что важно понять перед разбором

Проект специально показывает разницу между последовательностями, где `GetEnumerator` каждый раз создает новый перечислитель через `yield`, и `Odd`, где хранится один объект `OddEnumerator`.
