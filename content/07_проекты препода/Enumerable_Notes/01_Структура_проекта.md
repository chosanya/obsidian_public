# Структура проекта Enumerable

## Карта проекта

Название проекта: `Enumerable`

Назначение: демонстрация перечисляемых последовательностей и ручного перечислителя.

Технологии: C#, .NET 9.0, консольное приложение.

Точка входа: top-level statements в `Enumerable/Odd.cs`.

Основные папки:

- `Enumerable/` — основной проект.

Основные классы:

- [[Класс — Fibonacci]]
- [[Класс — Even]]
- [[Класс — Odd]]
- [[Класс — OddEnumerator]]

Архитектура: демонстрационный top-level код + классы последовательностей.

Связанные темы экзамена:

- перечислители `IEnumerable`, `IEnumerator`;
- `yield`;
- коллекции;
- исключения.
