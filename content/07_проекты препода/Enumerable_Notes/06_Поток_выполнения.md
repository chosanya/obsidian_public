# Поток выполнения Enumerable

## Общая схема

```text
Odd.cs
→ new Odd(0, 100)
→ foreach oddSequence
→ повторный foreach oddSequence
→ new Even(0, 100)
→ foreach evenSequence
→ new Fibonacci()
→ foreach fibo
→ повторный foreach fibo
```

## Факт проверки

Временная копия проекта успешно собирается. Были только предупреждения NuGet из-за сетевой проверки уязвимостей.

## Важный момент

`Odd` возвращает один и тот же `OddEnumerator`, а `Fibonacci` и `Even` создают перечислитель через `yield`. Поэтому повторный обход у этих классов устроен по-разному.
