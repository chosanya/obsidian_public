# Проблемные места Enumerable

## Активный код находится в `Odd.cs`

`Program.cs` пустой, а выполняемый top-level код находится в `Odd.cs`. Это может сбивать при поиске точки входа.

## `Odd` хранит один перечислитель

```csharp
private OddEnumerator enumerator;
```

Обычно `GetEnumerator` должен возвращать новый перечислитель.

## `Dispose` вызывает `Reset`

```csharp
public void Dispose()
{
    Reset();
}
```

Это учебное решение. В реальных перечислителях `Dispose` обычно освобождает ресурсы, а не обязательно сбрасывает состояние.

## Проверка переполнения в `Fibonacci`

`yield break` вызывается, когда `b < 0`. Это связано с переполнением `long`, но явно `checked` не используется.
