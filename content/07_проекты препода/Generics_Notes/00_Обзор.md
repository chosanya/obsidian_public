# Generics

## Что делает проект

Проект демонстрирует обобщения в C# на сравнении двух подходов:

- `A<T>` — типобезопасный обобщенный класс;
- `ABad` — класс, который хранит элементы как `object`.

Основная идея: показать, почему generic-классы лучше, чем хранение всего через `object`.

## Основные технологии

- C#.
- .NET 9.0.
- Консольное приложение.
- Generics.
- Ограничения типа `where`.
- Индексатор.

## Архитектура

Весь код находится в `Program.cs`.

```text
Program.cs
→ создание A<int>, A<double>, A<A<int>>
→ создание ABad
→ вывод объектов
→ суммирование через индексаторы
```

```bash

```

## Что важно понять перед разбором

Generic-класс позволяет сохранить информацию о типе элементов. Поэтому `A<int>` возвращает `int`, а `A<double>` возвращает `double`.

`ABad` возвращает `object`, поэтому программисту приходится вручную приводить типы, и ошибка может проявиться только во время выполнения.
