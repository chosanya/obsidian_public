# Структура проекта Generics

## Карта проекта

Название проекта: `Generics`

Назначение: демонстрация обобщений и сравнение generic-подхода с хранением через `object`.

Технологии: C#, .NET 9.0, консольное приложение.

Точка входа: `Generics/Program.cs`.

Основные классы:

- [[Класс — A<T>]]
- [[Класс — ABad]]

Архитектура: top-level statements + два учебных контейнерных класса.

Связанные темы экзамена:

- обобщения;
- индексаторы;
- массивы;
- интерфейсы как ограничения типа;
- приведение типов.
