# Темы ООП и C# в Generics

## Обобщения

### Где используется

- [[Класс — A<T>]]

### Фрагмент кода

```csharp
class A<T>
```

### Как объяснить преподавателю

Обобщение позволяет написать класс один раз, а использовать его с разными типами.

## Ограничения типа

### Где используется

- [[Класс — A<T>]]

### Фрагмент кода

```csharp
where T : struct, IComparable
```

### Как объяснить преподавателю

Ограничение говорит компилятору, какие типы можно подставлять вместо `T`.

Массив хранится внутри класса, а внешний доступ идет через индексатор.

## Приведение типов

### Фрагмент кода

Приведение может завершиться ошибкой во время выполнения, если объект фактически не является `int`.
