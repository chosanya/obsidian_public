# Поток выполнения Generics

## Общая схема

```text
Program.cs
→ создать A<int>, A<double>, A<A<int>>
→ создать ABad
→ вывести объекты
→ посчитать sum через A<int>
→ посчитать sum2 через ABad
→ завершение
```

## Пошагово

1. Создается `a1` типа `A<int>`.
2. Создается `a2` типа `A<double>`.
3. Создается `a3` типа `A<int>`.
4. Создается `a4` типа `A<A<int>>`.
5. Создаются объекты `ABad`.
6. Объекты выводятся через `Console.WriteLine`.
7. Считается сумма элементов `a1`.
8. Считается сумма элементов `ab1`, но с приведением `(int)`.
9. Программа завершается.

## Важное замечание

В текущем коде есть место, которое мешает компиляции:

```csharp
var a4 = new A<A<int>>([a1, a3]);
```

`A<T>` требует `where T : struct, IComparable`, а `A<int>` не является структурой. Проверка сборки временной копии подтвердила ошибку `CS0453`.
