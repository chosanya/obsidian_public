# Темы ООП и C# в IEnum

## Интерфейсы

`Nodes` реализует `IReadOnlyCollection<double>`.

## Коллекции

Класс `Nodes` ведет себя как коллекция только для чтения: есть `Count`, `foreach` и индексатор.

## `yield return`

Используется в `GetEnumerator` для равномерных узлов.

## Индексатор

`this[int index]` позволяет получить узел по номеру.

## Исключения

Конструктор выбрасывает `ArgumentException` при неправильных параметрах. Индексатор выбрасывает `ArgumentException` при неправильном индексе.

## Перечисления

`NodesType` задает способ построения узлов.

## WPF, MVVM, БД, async/await

Не используются.
