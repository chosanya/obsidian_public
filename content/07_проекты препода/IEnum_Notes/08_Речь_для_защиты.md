# Защита проекта IEnum

## Что делает проект

Проект показывает, как создать собственную коллекцию узлов на отрезке. Класс `Nodes` реализует `IReadOnlyCollection<double>`, поэтому его можно обходить через `foreach`.

## Архитектура

Весь код находится в `Program.cs`. Есть перечисление `NodesType` и класс `Nodes`.

## Основные классы

`Nodes` хранит границы отрезка, количество узлов и тип построения. Для равномерных узлов он генерирует значения через `yield return`.

## Принципы ООП

Главная тема — интерфейсы и коллекции. Класс реализует стандартный интерфейс, поэтому получает стандартное поведение для `foreach`.

Также есть инкапсуляция: поля скрыты внутри класса.

## Как работает программа

Программа создает равномерные узлы на отрезке от `-1` до `1`, выводит их через `foreach`, а затем получает узел по индексу.

## Что можно улучшить

Можно реализовать ветки `Chebyshev` и `Random`, а также заменить индексатор на более эффективный способ, если узлы будут храниться в массиве.
