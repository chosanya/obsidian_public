# Проблемные места IEnum

## Не реализованы `Chebyshev` и `Random`

В `switch` есть ветки:

```csharp
case NodesType.Chebyshev:
case NodesType.Random:
```

Но внутри них нет генерации значений.

## Индексатор работает через перебор

Чтобы получить элемент по индексу, код обходит последовательность с начала.

Это понятно для учебного примера, но может быть неэффективно для больших коллекций.

## Лишний `using`

`using System.Diagnostics;` подключен, но в коде не используется.

## Возврат `Double.NaN`

После проверки индекса и перебора есть:

```csharp
return Double.NaN;
```

В нормальном сценарии эта строка недостижима для реализованного `Equidistant`, но при пустых ветках `Chebyshev` или `Random` индексатор может дойти до нее.
