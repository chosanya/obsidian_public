# Integr

## Что делает проект

`Integr` — WPF-приложение для численного вычисления интеграла функции

```text
f(x) = sin(x^2) + 5cos^2(2x)
```

методом средних прямоугольников.

Пользователь вводит:

- левую границу `a`;
- правую границу `b`;
- количество разбиений `n`.

После нажатия кнопки программа считает результат и выводит его в окно.

## Основные технологии

- C#.
- .NET 10.0 Windows.
- WPF.
- XAML.
- Обработчик события `Click`.
- `MessageBox`.

## Архитектура

Это WPF без MVVM.

```text
App.xaml
→ MainWindow.xaml
→ Button_Click
→ Integrator
→ Result.Text
```

На Windows:

```bash
dotnet run --project Integr/Integr.csproj
```

## Важное про проверку

В текущей macOS-среде проект не собирается из-за WPF-таргета `net10.0-windows`. Ошибка проверки: `NETSDK1100`, требуется Windows targeting. Это ограничение среды, а не автоматическая правка проекта.
