# Класс — Integrator

## Исходный файл

`Integr/Integrator.cs`

## Назначение класса

`Integrator` содержит вычислительную логику: функцию `F(x)` и метод численного интегрирования методом средних прямоугольников.

## Свойства

```csharp
public double A { get; set; }
public double B { get; set; }
public int N { get; set; }
```

`A` и `B` — границы интегрирования, `N` — количество разбиений.

## Конструктор

```csharp
public Integrator(double a=0.0, double b=1.0, int n=10)
```

Параметры имеют значения по умолчанию.

## Методы

```csharp
public double F(double x)
```

Возвращает значение функции.

```csharp
public double IntegrateByMidpointRule()
```

Считает интеграл методом средних прямоугольников.

## Что сказать на экзамене

Класс отделяет математическую логику от интерфейса. Окно только читает данные и показывает результат, а вычисления выполняет `Integrator`.
