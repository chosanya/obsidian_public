# Темы ООП и C# в Integr

## Классы и объекты

`Integrator`, `MainWindow`, `App`.

## Свойства и методы

`Integrator` содержит свойства `A`, `B`, `N` и методы `F`, `IntegrateByMidpointRule`.

## WPF

Используются `Application`, `Window`, `Grid`, `TextBox`, `Button`, `TextBlock`.

## События

Кнопка связана с обработчиком:

```xml
Click="Button_Click"
```

## Исключения

Ввод обрабатывается через `try/catch`.

## MVVM, Data Binding, ICommand, БД, async/await

Не используются.
