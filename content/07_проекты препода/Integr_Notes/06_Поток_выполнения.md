# Поток выполнения Integr

## Общая схема

```text
App.xaml
→ MainWindow.xaml
→ MainWindow()
→ InitializeComponent()
→ Button_Click
→ Integrator
→ Result.Text
```

## Пошагово

1. WPF запускает `App`.
2. `StartupUri` открывает `MainWindow`.
3. Пользователь вводит `a`, `b`, `n`.
4. Пользователь нажимает кнопку.
5. Вызывается `Button_Click`.
6. Текст из полей преобразуется в числа.
7. Создается `Integrator`.
8. Вызывается `IntegrateByMidpointRule`.
9. Результат записывается в `Result.Text`.

## Факт проверки

На текущей macOS-среде сборка завершилась ошибкой `NETSDK1100`, потому что проект таргетит `net10.0-windows`. Для сборки на не-Windows требуется `EnableWindowsTargeting=true`; исходный код не менялся.
