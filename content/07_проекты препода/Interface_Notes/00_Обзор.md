# Interface

## Что делает проект

Проект демонстрирует интерфейсы `ICloneable` и `IComparable` на примере класса `A`, который хранит массив целых чисел.

В коде показано:

- создание объекта;
- клонирование объекта;
- отличие копии от ссылки на тот же объект;
- индексатор;
- сравнение объектов через `IComparable`;
- обработка неподходящего типа через исключение.

## Основные технологии

- C#.
- .NET 9.0.
- Консольное приложение.
- `ICloneable`.
- `IComparable`.

## Архитектура

Весь код расположен в `Program.cs`.

```text
Program.cs
→ class A : ICloneable, IComparable
→ CompareValues(IComparable a, IComparable b)
```

## Что важно понять перед разбором

Главная идея проекта: объект можно передавать в метод не только по конкретному классу, но и по интерфейсу. Метод `CompareValues` принимает `IComparable`, поэтому он может сравнивать разные объекты, если они реализуют этот интерфейс.
