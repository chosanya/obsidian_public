# Темы ООП и C# в Interface

## Интерфейсы

### Где используется

- [[Класс — A]]

### Фрагмент кода

```csharp
class A : ICloneable, IComparable
```

### Как объяснить преподавателю

Интерфейс задает контракт. Если класс реализует `IComparable`, он обязан иметь метод `CompareTo`.

## Полиморфизм через интерфейс

### Где используется

- [[Program.cs]]

```csharp
void CompareValues(IComparable a, IComparable b)
```

Метод работает с любыми объектами, которые реализуют `IComparable`.

## Инкапсуляция

### Где используется

- [[Класс — A]]

Массив `arr` скрыт внутри класса, а доступ к нему идет через индексатор.

## Индексатор

```csharp
public int this[int i]
```

Позволяет обращаться к объекту как к массиву.

## Исключения

```csharp
throw new ArgumentException("Объекты нельзя сравнить");
```

Исключение выбрасывается, если объект нельзя сравнить с `A`.

## WPF, MVVM, БД, async/await

Не используются.
