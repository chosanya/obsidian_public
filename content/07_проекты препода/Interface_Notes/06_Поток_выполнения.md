# Поток выполнения Interface

## Общая схема

```text
Program.cs
→ создать a1
→ создать a2 через Clone
→ создать a3 как ссылку на a1
→ изменить a1[0]
→ вывести a1, a2, a3
→ сравнить значения через IComparable
```

## Пошагово

1. Создается объект `a1`.
2. Через `Clone` создается отдельная копия `a2`.
3. `a3 = a1` создает вторую ссылку на тот же объект.
4. Через индексатор меняется первый элемент `a1`.
5. Вывод показывает разницу между копией и ссылкой.
6. `CompareValues(a1, a2)` сравнивает два объекта `A`.
7. `CompareValues(33, 161)` сравнивает два числа, потому что `int` тоже реализует `IComparable`.
8. `CompareValues(a2, 111)` вызывает исключение внутри `A.CompareTo`, потому что `A` не умеет сравниваться с `int`.
