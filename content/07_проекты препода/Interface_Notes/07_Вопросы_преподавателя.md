# Вопросы преподавателя по Interface

## Что такое интерфейс?

### Ответ

Интерфейс — это контракт, который задает, какие методы или свойства должен реализовать класс.

## Почему `A` можно передать в `CompareValues`?

### Ответ

Потому что `A` реализует `IComparable`, а метод принимает параметры типа `IComparable`.

## Чем `a2` отличается от `a3`?

### Ответ

`a2` — отдельная копия, созданная через `Clone`. `a3` — ссылка на тот же объект, что и `a1`.

## Что делает `ICloneable`?

### Ответ

Он требует метод `Clone`, который создает копию объекта.

## Что делает `IComparable`?

### Ответ

Он требует метод `CompareTo`, который сравнивает текущий объект с другим.

## Почему возникает `ArgumentException`?

### Ответ

Потому что `A.CompareTo` умеет сравнивать только с другим `A`. Если передать другой тип, метод выбрасывает исключение.
