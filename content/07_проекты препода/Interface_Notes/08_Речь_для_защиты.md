# Защита проекта Interface

## Что делает проект

Проект показывает, как класс может реализовывать стандартные интерфейсы `ICloneable` и `IComparable`.

## Архитектура

Весь код находится в `Program.cs`. Основной класс `A` хранит массив и реализует два интерфейса.

## Основные классы

`A` хранит массив `int[]`, предоставляет индексатор, умеет создавать копию через `Clone`, выводиться как строка и сравниваться с другим `A` через `CompareTo`.

## Принципы ООП

Главная тема — интерфейсы. Метод `CompareValues` принимает `IComparable`, поэтому может работать с любыми объектами, которые поддерживают сравнение.

Также есть инкапсуляция: массив скрыт внутри класса.

## Как работает программа

Программа создает объект, его копию и еще одну ссылку на исходный объект. После изменения первого элемента видно, что копия не изменилась, а ссылка показывает то же состояние. Затем объекты сравниваются через интерфейс `IComparable`.

## Что можно улучшить

Можно заменить устаревший негeneric `IComparable` на `IComparable<A>` для большей типобезопасности.
