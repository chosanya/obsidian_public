# Проблемные места Interface

## `CompareValues(a2, 111)` приводит к исключению

Метод `CompareValues` принимает `IComparable`, но это не гарантирует, что любые два переданных объекта можно сравнить между собой.

`A.CompareTo` умеет сравнивать только с `A`, поэтому при сравнении с `int` выбрасывается `ArgumentException`.

## Используется негeneric `IComparable`

```csharp
class A : ICloneable, IComparable
```

Для более строгой типизации можно было бы использовать `IComparable<A>`, но исходный код не меняем.

## `ICloneable` возвращает `object`

Из-за этого приходится писать:

```csharp
var a2 = (A)a1.Clone();
```

Это стандартное поведение интерфейса, но оно менее удобно, чем типизированный метод копирования.

## Поле без явного `private`

```csharp
int[] arr;
```

В C# это приватное поле по умолчанию, но для читаемости обычно пишут `private`.
