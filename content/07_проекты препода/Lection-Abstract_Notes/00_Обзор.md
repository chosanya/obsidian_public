# Lection-Abstract

## Что делает проект

Проект демонстрирует абстрактный класс и наследование на примере разных способов построения узлов на отрезке.

В проекте есть:

- абстрактный базовый класс `Nodes`;
- наследник `EqvidNodes` для равномерных узлов;
- наследник `ChebyshevNodes` для узлов Чебышева;
- наследник `RandomNodes` для случайных узлов;
- абстрактный индексатор, переопределенный в наследниках.

## Основные технологии

- C#.
- .NET 9.0.
- Консольное приложение.
- Абстрактные классы.
- Наследование.
- `override`.
- Индексаторы.

## Архитектура

```text
Nodes
├── EqvidNodes
├── ChebyshevNodes
└── RandomNodes
```

`Program.cs` создает объекты наследников и выводит значения узлов через индексатор.

## Что важно понять перед разбором

`Nodes` задает общую структуру: левую границу, правую границу, количество узлов и требование “уметь вернуть узел по индексу”.

Наследники реализуют конкретную формулу получения узла.
