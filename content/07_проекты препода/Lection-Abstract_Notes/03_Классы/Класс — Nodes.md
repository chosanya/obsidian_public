# Класс — Nodes

## Исходный файл

`Lection-Abstract/Nodes.cs`

## Назначение класса

`Nodes` — абстрактный базовый класс для наборов узлов на отрезке.

## Поля

```csharp
double _left;
double _right;
int _count;
```

Поля хранят левую границу, правую границу и количество узлов.

## Свойства

```csharp
public double Left => _left;
public double Right => _right;
public int Count => _count;
```

Свойства только для чтения.

## Конструкторы

```csharp
public Nodes(double a, double b, int n)
```

Задает границы и количество узлов.

```csharp
public Nodes(int n) : this(0.0, 1.0, n) { }
```

Перегруженный конструктор задает отрезок по умолчанию `[0, 1]`.

## Абстрактный индексатор

```csharp
public abstract double this[int index] { get; }
```

Базовый класс требует, чтобы наследники умели возвращать узел по индексу.

## Что сказать на экзамене

`Nodes` нельзя использовать напрямую, потому что он абстрактный. Он задает общий интерфейс и общие данные для наследников.
