# Темы ООП в Lection-Abstract

## Абстрактные классы

### Где используется

- [[Класс — Nodes]]

```csharp
public abstract class Nodes
```

`Nodes` нельзя создать напрямую, он нужен как базовый класс.

## Наследование

### Где используется


## Переопределение

### Где используется

Во всех наследниках:

```csharp
public override double this[int index]
```

## Полиморфизм

Все наследники имеют общий тип `Nodes`, но реализуют индексатор по-разному.

## Инкапсуляция

Поля `_left`, `_right`, `_count` скрыты внутри базового класса, наружу отданы свойства только для чтения.

## Индексаторы

Абстрактный индексатор объявлен в базовом классе и реализован в наследниках.

## WPF, MVVM, БД, async/await

Не используются.
