# Поток выполнения Lection-Abstract

## Общая схема

```text
Program.cs
→ new EqvidNodes(11)
→ вывод en[i]
→ new ChebyshevNodes(5)
→ вывод chn[i]
→ new RandomNodes(5)
→ вывод rn[i]
```

## Пошагово

1. Подключается пространство имен `Lection_Abstract`.
2. Создается `EqvidNodes`.
3. Конструктор `EqvidNodes` вызывает `base(n)`.
4. `base(n)` вызывает конструктор `Nodes` с отрезком `[0, 1]`.
5. Цикл выводит равномерные узлы через индексатор.
6. Создается `ChebyshevNodes`.
7. Цикл выводит узлы Чебышева.
8. Создается `RandomNodes`.
9. Конструктор генерирует массив случайных узлов и сортирует его.
10. Цикл выводит случайные узлы.
