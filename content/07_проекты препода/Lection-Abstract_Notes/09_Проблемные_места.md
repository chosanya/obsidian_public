# Проблемные места Lection-Abstract

## Нет проверки параметров

В `Nodes` не проверяется, что `a < b` и `n > 1`. Если передать некорректные параметры, формулы могут работать неправильно.

## Нет проверки индекса

Индексаторы не проверяют, входит ли `index` в допустимый диапазон. Для `RandomNodes` неверный индекс приведет к стандартному исключению массива.

## Много лишних `using`

В нескольких файлах есть `using`, которые фактически не используются. Это не ломает проект, но делает код менее чистым.

## Полиморфизм не показан явно в `Program.cs`

Код создает переменные конкретных типов:

```csharp
EqvidNodes en = new EqvidNodes(11);
ChebyshevNodes chn = new ChebyshevNodes(5);
RandomNodes rn = new RandomNodes(5);
```

Для демонстрации полиморфизма можно было бы использовать переменную типа `Nodes`, но исходный код не меняем.
