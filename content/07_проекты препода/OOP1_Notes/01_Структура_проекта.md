# Структура проекта OOP1

## Карта проекта

Название проекта: `OOP1`

Назначение: учебный пример класса комплексного числа.

Технологии: C#, .NET 9.0, xUnit.

Точка входа: `OOP1/Program.cs`.

Основные папки:

- `OOP1/` — основное консольное приложение.
- `TestComplex/` — тестовый проект.

Основные классы:

- [[Класс — Complex]]
- `ComplexTest`

Архитектура: одно доменное понятие (`Complex`) и отдельный тестовый проект.

Связанные темы экзамена:

- классы и объекты;
- поля и свойства;
- конструкторы;
- инкапсуляция;
- индексаторы;
- перегрузка операторов;
- переопределение методов;
- сравнение объектов.

## Файлы решения

```text
OOP1.sln
OOP1/
  OOP1.csproj
  Program.cs
TestComplex/
  TestComplex.csproj
  ComplexTest.cs
```

## `.sln`

Файл `OOP1.sln` объединяет два проекта:

- `OOP1` — основной проект;
- `TestComplex` — тесты.

## `.csproj` основного проекта

Путь: `OOP1/OOP1.csproj`

Проект настроен как консольное приложение под `net9.0`.

## `.csproj` тестового проекта

Путь: `TestComplex/TestComplex.csproj`

Тестовый проект использует:

- `xunit`;
- `xunit.runner.visualstudio`;
- `Microsoft.NET.Test.Sdk`;
- `coverlet.collector`;
- ссылку на основной проект `..\OOP1\OOP1.csproj`.

## Какие файлы разобраны

- [[Program.cs]]
- [[ComplexTest.cs]]
- [[OOP1.csproj]]
- [[TestComplex.csproj]]
