# Класс — Complex

## Исходный файл

`OOP1/Program.cs`

## Назначение класса

`Complex` описывает комплексное число. Объект класса хранит действительную и мнимую части и предоставляет операции для работы с комплексными числами.

## Поля

```csharp
double _re;
private double _im;
```

Факты из кода:

- `_re` хранит действительную часть.
- `_im` хранит мнимую часть.
- `_im` явно объявлено как `private`.
- `_re` не имеет модификатора доступа, значит в C# оно тоже приватное по умолчанию для члена класса.

Пояснение:

Оба поля фактически скрыты от внешнего кода. Это основа [[Инкапсуляция|инкапсуляции]].

## Свойства

```csharp
public double Re
{
    get { return _re; }
    set { _re = value; }
}

public double Im
{
    get => _im;
    set => _im = value;
}
```

`Re` и `Im` дают публичный доступ к частям комплексного числа.

```csharp
public double Abs => Math.Sqrt(_re * _re + _im * _im);
```

`Abs` — вычисляемое свойство. Оно не хранит отдельное поле, а каждый раз считает модуль комплексного числа.

## Конструкторы

```csharp
public Complex(double re = 0.0, double im = 0.0)
{
    Re = re;
    Im = im;
}
```

Конструктор принимает два необязательных параметра. Поэтому возможны варианты:

- `new Complex()` — создается `0 + 0i`;
- `new Complex(5)` — создается `5 + 0i`;
- `new Complex(1, 2)` — создается `1 + 2i`.

## Индексатор

```csharp
public double? this[string part]
{
    get
    {
        switch (part.ToLower())
        {
            case "re":
            case "r":
            case "real":
                {
                    return Re;
                }
            case "im":
            case "i":
            case "imaginary":
                {
                    return Im;
                }
            default:
                return null;
        }
    }
}
```

Индексатор позволяет обращаться к частям числа как к элементам объекта:

```csharp
z9["Re"]
z9["i"]
```

Если передана неизвестная строка, возвращается `null`.

Связанная тема: создание индексатора.

## Методы

### `ToString`

```csharp
public override string ToString()
```

Формирует строку вида:

- `0`;
- `1`;
- `i`;
- `-i`;
- `1+i`;
- `2-2,5i`.

Метод использует `StringBuilder`, условия и `Math.Abs`.

### `Plus` как метод экземпляра

```csharp
public Complex Plus(Complex other)
{
    return new Complex(this.Re + other.Re, Im + other.Im);
}
```

Метод складывает текущий объект с другим комплексным числом.

### `Plus` как статический метод

```csharp
public static Complex Plus(Complex z1, Complex z2)
{
    return new Complex(z1.Re + z2.Re, z1.Im + z2.Im);
}
```

Статический метод делает то же сложение, но принимает оба числа как параметры.

## Операторы

```csharp
public static Complex operator+(Complex z1, Complex z2)
```

Позволяет писать:

```csharp
var z12 = z8 + z9;
```

```csharp
public static Complex operator -(Complex z1, Complex z2)
```

Вычитает одно комплексное число из другого.

```csharp
public static Complex operator -(Complex z1)
```

Унарный минус меняет знак мнимой части.

> [!warning]
> В математике унарный минус обычно меняет знак обеих частей комплексного числа. В коде меняется только `Im`. Это не исправляется автоматически, но это место стоит уметь объяснить.

## Преобразования типов

```csharp
public static explicit operator double(Complex z) => z.Re;
public static implicit operator Complex(double z) => new(z, 0);
```

Факты из кода:

- `Complex` можно явно привести к `double`, при этом берется только `Re`.
- `double` можно неявно превратить в `Complex` с нулевой мнимой частью.

## Сравнение

```csharp
public static bool operator ==(Complex z1, Complex z2)
public static bool operator !=(Complex z1, Complex z2)
public override bool Equals(object? obj)
public override int GetHashCode()
```

Класс переопределяет сравнение:

- через операторы `==` и `!=`;
- через `Equals`;
- через `GetHashCode`.

Это важно, потому что без переопределения `Equals` объекты классов обычно сравниваются по ссылке, а не по содержимому.

## Интерфейсы и наследование

Класс не наследуется от пользовательского базового класса и не реализует интерфейсы.

Но он переопределяет методы базового класса `object`:

- `ToString`;
- `Equals`;
- `GetHashCode`.

## Какие объекты создаются

В демонстрационном коде и тестах создаются объекты:

```csharp
new Complex()
new Complex(2, 1)
new Complex(-2.1, 3)
new Complex(0.1, 3.3)
```

## Какие принципы ООП используются

- [[Классы и объекты]] — `Complex` является классом, а `new Complex(...)` создает объекты.
- [[Инкапсуляция]] — поля скрыты, доступ идет через свойства.
- Полиморфизм методов `object` — `ToString`, `Equals`, `GetHashCode` переопределены под смысл комплексного числа.

## Что сказать на экзамене

`Complex` — это учебный класс, который моделирует комплексное число. Он хранит состояние в полях `_re` и `_im`, предоставляет доступ через свойства `Re` и `Im`, умеет вычислять модуль, складываться с другими комплексными числами, преобразовываться в строку и сравниваться по значению.

## Возможные вопросы преподавателя

### Почему поля сделаны закрытыми?

Чтобы внешний код не работал напрямую с внутренним состоянием объекта. Это позволяет контролировать доступ через свойства.

### Чем свойство отличается от поля?

Поле хранит данные, а свойство задает публичный способ доступа к этим данным и может содержать дополнительную логику в `get` и `set`.

### Зачем переопределять `Equals`?

Чтобы сравнивать комплексные числа по значениям `Re` и `Im`, а не по ссылкам на объекты.

### Почему вместе с `Equals` переопределен `GetHashCode`?

Это стандартное правило C#: если объекты считаются равными через `Equals`, они должны иметь согласованный хеш-код для корректной работы в хеш-коллекциях.
