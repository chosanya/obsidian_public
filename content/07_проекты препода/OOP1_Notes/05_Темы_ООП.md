# Темы ООП в OOP1

## Классы и объекты

### Где используется

- [[Класс — Complex]]
- [[Program.cs]]
- [[ComplexTest.cs]]

### Фрагменты кода

```csharp
public class Complex
```

```csharp
var c1 = new Complex();
var c2 = new Complex(2, 1);
```

### Почему это классы и объекты

`Complex` — это описание типа. `new Complex(...)` создает конкретный объект этого типа.

### Как объяснить преподавателю

Класс задает структуру и поведение комплексного числа, а объект — конкретное комплексное число с собственными значениями `Re` и `Im`.

### Почему это важно

Поля хранят данные, а свойства дают внешний доступ к ним.

## Конструкторы

### Где используется

- [[Класс — Complex]]

### Фрагменты кода

```csharp
public Complex(double re = 0.0, double im = 0.0)
{
    Re = re;
    Im = im;
}
```

### Как объяснить преподавателю

Конструктор вызывается при создании объекта и задает начальное состояние комплексного числа.

## Исключения

В проекте `OOP1` явная обработка исключений почти не используется. Но потенциально исключение может возникнуть в индексаторе, если `part` будет `null`, потому что вызывается `part.ToLower()`.

- WinForms;
