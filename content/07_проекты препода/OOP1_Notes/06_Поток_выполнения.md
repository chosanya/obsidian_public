# Поток выполнения OOP1

## Общая схема

```text
Program.cs
→ Console.WriteLine()
→ завершение программы
```

## Пошагово

1. Запускается консольное приложение `OOP1`.
2. Выполняются top-level statements в `Program.cs`.
3. Большой демонстрационный блок находится в комментарии и не выполняется.
4. Выполняется активная строка:

```csharp
Console.WriteLine();
```

5. Программа выводит пустую строку.
6. Программа завершается.

## Где создается первый объект

В текущем активном коде объект `Complex` не создается.

В закомментированном демонстрационном коде первым создавался бы объект:

```csharp
Complex z1 = new Complex();
```

В тестах первым создается:

```csharp
var c1 = new Complex();
```

## Как работают тесты

```text
dotnet test
→ xUnit находит ComplexTest
→ запускает методы с [Fact] и [Theory]
→ создает объекты Complex
→ проверяет свойства, операторы и ToString
```

## Важное отличие от WPF-проектов

В этом проекте нет цепочки:

```text
Program
→ App
→ MainWindow
→ MainViewModel
→ Command
→ Model/Service
→ обновление UI
```

Вместо этого здесь простая консольная программа и отдельный тестовый проект.
