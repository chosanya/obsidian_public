# Вопросы преподавателя по OOP1

## Что такое класс на примере этого проекта?

### Ответ

Класс — это описание типа объектов. В проекте класс `Complex` описывает комплексное число: какие данные оно хранит и какие операции над ним можно выполнять.

## Что такое объект?

### Ответ

Объект — это конкретный экземпляр класса. Например, `new Complex(2, 1)` создает объект комплексного числа с действительной частью `2` и мнимой частью `1`.

## Где здесь инкапсуляция?

### Ответ

Инкапсуляция проявляется в том, что поля `_re` и `_im` скрыты внутри класса, а доступ к ним идет через свойства `Re` и `Im`.

## Чем поле отличается от свойства?

### Ответ

Поле непосредственно хранит данные объекта. Свойство задает внешний интерфейс доступа к этим данным и может контролировать чтение или запись через `get` и `set`.

## Зачем нужен конструктор?

### Ответ

Конструктор задает начальное состояние объекта. В `Complex` конструктор записывает значения действительной и мнимой частей.

## Почему конструктор можно вызвать без параметров?

### Ответ

Потому что оба параметра имеют значения по умолчанию:

```csharp
public Complex(double re = 0.0, double im = 0.0)
```

## Что такое индексатор?

### Ответ

Индексатор позволяет обращаться к объекту через квадратные скобки. В `Complex` индексатор принимает строку и возвращает `Re` или `Im`.

## Зачем перегружать оператор `+`?

### Ответ

Чтобы комплексные числа можно было складывать естественно:

```csharp
var c3 = c1 + c2;
```

Это делает пользовательский класс похожим на встроенные числовые типы.

## Почему переопределен `ToString`?

### Ответ

Чтобы объект выводился в понятном математическом виде, например `1+i`, а не как имя типа.

## Почему переопределен `Equals`?

### Ответ

Чтобы сравнивать комплексные числа по значениям `Re` и `Im`, а не по ссылкам.

## Почему вместе с `Equals` нужен `GetHashCode`?

### Ответ

Это правило корректного сравнения объектов в C#: равные объекты должны иметь согласованный хеш-код, особенно если они используются в коллекциях вроде словаря или множества.

## Что делает явное преобразование к `double`?

### Ответ

Оно возвращает действительную часть комплексного числа:

```csharp
public static explicit operator double(Complex z) => z.Re;
```

## Что делает неявное преобразование из `double`?

### Ответ

Оно создает комплексное число с нулевой мнимой частью:

```csharp
public static implicit operator Complex(double z) => new(z, 0);
```

## Есть ли в проекте наследование?

### Ответ

Пользовательского наследования нет. Но класс `Complex` неявно наследуется от `object` и переопределяет его методы `ToString`, `Equals`, `GetHashCode`.

## Есть ли в проекте MVVM?

### Ответ

Нет. Это консольный проект без графического интерфейса, `View`, `ViewModel`, `DataContext` и `ICommand`.
