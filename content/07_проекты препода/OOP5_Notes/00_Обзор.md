# OOP5

## Что делает проект

`OOP5` — учебное консольное приложение, которое демонстрирует работу с массивами и перечислениями в C#.

В проекте показаны:

- одномерный массив `int[]`;
- зубчатый массив `int[][]`;
- двумерный массив `int[,]`;
- вложенные циклы;
- методы класса `Array`;
- вывод массива через `string.Join`;
- перечисление `enum`;
- атрибут `[Flags]`;
- битовые значения элементов перечисления.

## Основные технологии

- C#.
- .NET 9.0.
- Консольное приложение.

## Архитектура

Архитектура очень простая: весь учебный код находится в `Program.cs`.

Формальных классов модели, сервисов, View или ViewModel нет.

## Главные элементы

- `int[] a` — одномерный массив.
- `int[][] mas21` — зубчатый массив.
- `int[,] mas22` — двумерный массив.
- [[Перечисление — DayOfWeek]] — перечисление дней недели с атрибутом `[Flags]`.

## Какие темы экзамена демонстрирует

- работа с массивами;
- одномерные массивы;
- зубчатые массивы;
- двумерные массивы;
- циклы `for`;
- перечисления `enum`;
- атрибут `[Flags]`;
- битовые флаги;
- явное приведение `enum` к числу.

## Как запустить

Из корня репозитория:

```bash
dotnet run --project OOP5/OOP5.csproj
```

## Что важно понять перед разбором

Проект не демонстрирует полноценную объектную архитектуру. Его задача — показать базовые структуры данных C# и то, чем разные виды массивов отличаются друг от друга.

Самая важная мысль: `int[][]` и `int[,]` — это разные типы массивов. Первый хранит массивы внутри массива, а второй является прямоугольной таблицей фиксированного размера.
