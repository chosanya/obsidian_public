# Структура проекта OOP5

## Карта проекта

Название проекта: `OOP5`

Назначение: демонстрация массивов и перечислений.

Технологии: C#, .NET 9.0, консольное приложение.

Точка входа: `OOP5/Program.cs`.

Основные папки:

- `OOP5/` — основной проект.

Основные элементы:

- одномерный массив `a`;
- зубчатый массив `mas21`;
- двумерный массив `mas22`;
- [[Перечисление — DayOfWeek]].

Архитектура: top-level statements в одном файле.

Связанные темы экзамена:

- работа с массивами;
- перечисления;
- базовый синтаксис C#;
- битовые флаги.

## Файлы решения

```text
OOP5.sln
OOP5/
  OOP5.csproj
  Program.cs
```

## `.sln`

Файл `OOP5.sln` содержит один проект:

- `OOP5`.

## `.csproj`

Путь: `OOP5/OOP5.csproj`

Проект настроен как консольное приложение под `net9.0`.
