# Перечисление — DayOfWeek

## Исходный файл

`OOP5/Program.cs`

## Назначение

`DayOfWeek` — пользовательское перечисление, которое задает дни недели как именованные константы.

В этом проекте перечисление дополнительно помечено атрибутом `[Flags]`, а значения заданы в двоичном виде. Это позволяет комбинировать несколько значений через битовую операцию `|`.

## Исходный код

```csharp
[Flags]
public enum DayOfWeek : byte
{
    Monday = 0b_0000_0001,
    Tuesday = 0b_0000_0010,
    Wednesday = 0b_0000_0100,
    Thursday = 0b_0000_1000,
    Friday = 0b_0001_0000,
    Saturday = 0b_0010_0000,
    Sunday = 0b_0100_0000,
    Weekend = Saturday | Sunday,
}
```

## Элементы перечисления

| Элемент | Значение | Смысл |
|---|---:|---|
| `Monday` | `0b_0000_0001` | понедельник |
| `Tuesday` | `0b_0000_0010` | вторник |
| `Wednesday` | `0b_0000_0100` | среда |
| `Thursday` | `0b_0000_1000` | четверг |
| `Friday` | `0b_0001_0000` | пятница |
| `Saturday` | `0b_0010_0000` | суббота |
| `Sunday` | `0b_0100_0000` | воскресенье |
| `Weekend` | `Saturday | Sunday` | выходные |

## Почему указан `: byte`

```csharp
public enum DayOfWeek : byte
```

Факты из кода:

- базовый тип перечисления — `byte`;
- значит каждое значение хранится как байт.

Пояснение:

По умолчанию `enum` использует `int`, но здесь преподаватель явно показывает, что базовый тип можно изменить.

## Что делает `[Flags]`

`[Flags]` показывает, что элементы перечисления можно воспринимать как независимые битовые флаги.

Например:

```csharp
Weekend = Saturday | Sunday
```

означает, что `Weekend` состоит из двух флагов: `Saturday` и `Sunday`.

## Какие темы ООП и C# используются

- перечисления;
- атрибуты;
- битовые операции;
- именованные константы;
- приведение enum к числу.

## С кем взаимодействует

В `Program.cs` используется строка:

```csharp
var day = DayOfWeek.Wednesday;
Console.WriteLine((int)day);
```

Она создает переменную перечисления и выводит ее числовое значение.

## Что сказать на экзамене

`enum` нужен, чтобы заменить набор непонятных чисел понятными именами. В этом проекте дни недели хранятся как флаги, поэтому каждому дню назначено отдельное битовое значение. Атрибут `[Flags]` подчеркивает, что значения можно комбинировать.

## Возможные вопросы преподавателя

### Почему значения идут как `1`, `2`, `4`, `8`, а не `1`, `2`, `3`, `4`?

Потому что каждое значение занимает отдельный бит. Это нужно, чтобы можно было объединять значения через `|`.

### Что означает `Weekend = Saturday | Sunday`?

Это комбинированное значение, которое включает два флага: субботу и воскресенье.

### Что выведет `(int)DayOfWeek.Wednesday`?

Будет выведено `4`, потому что `Wednesday = 0b_0000_0100`.
