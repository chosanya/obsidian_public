# Темы ООП и C# в OOP5

## Работа с массивами

### Где используется

- [[Program.cs]]

### Фрагменты кода

```csharp
int[] a = { 1, 2, 3, 4, 5, 6, 7, 8, 9, 0};
```

```csharp
int[][] mas21 = new int[6][];
```

```csharp
int[,] mas22 = new int[6, 3];
```

### Почему это важно

Проект показывает три разные формы массивов. Это напрямую связано с экзаменационной темой “Работа с массивами”.

### Как объяснить преподавателю

`int[]` — линейная последовательность элементов. `int[][]` — массив ссылок на другие массивы. `int[,]` — прямоугольная таблица элементов.

## Зубчатые массивы

### Где используется

- [[Program.cs]]

### Фрагменты кода

```csharp
mas21[i] = new int[i % 3 + 1];
```

### Почему это зубчатый массив

Каждый элемент `mas21[i]` является отдельным массивом. Поэтому строки могут иметь разную длину.

## Двумерные массивы

### Где используется

- [[Program.cs]]

### Фрагменты кода

```csharp
int[,] mas22 = new int[6, 3];
mas22[i, j] = k++;
```

### Почему это двумерный массив

Доступ идет по двум индексам сразу: строка и столбец.

## Атрибут `[Flags]`

### Где используется

- [[Перечисление — DayOfWeek]]

### Фрагменты кода

```csharp
[Flags]
public enum DayOfWeek : byte
```

```csharp
Weekend = Saturday | Sunday,
```

### Почему это флаги

Каждому элементу соответствует отдельный бит. Поэтому значения можно объединять через `|`.
