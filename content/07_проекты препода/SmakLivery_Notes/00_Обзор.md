# SmakLivery

## Что делает проект

`SmakLivery` — WPF-приложение для просмотра, создания, редактирования и удаления заказов доставки через PostgreSQL.

## Факты из кода

- Проект таргетит `net10.0-windows` и использует WPF.
- В `SmakLivery.csproj` подключен пакет `Npgsql` версии `10.0.2`.
- При старте приложение вызывает `DbHelper.CreateDbAsync()`.
- Основное окно показывает список заказов через `ListView`.
- Окно добавления и редактирования использует отдельную ViewModel `AddEditViewModel`.
- Заказы загружаются из PostgreSQL через SQL-запрос с `JOIN` таблиц `order` и `courier`.

## Как запустить

На Windows с установленным PostgreSQL и базой `smaklivery`:

```bash
dotnet run --project SmakLivery/SmakLivery.csproj
```

## Важное про проверку

В текущей macOS-среде проект ожидаемо проблемно собирать как обычное приложение, потому что он таргетит `net10.0-windows` и использует WPF. Подключение к БД также зависит от локального PostgreSQL с параметрами из [[Класс — DbHelper]].
