# Архитектура SmakLivery

## Факты из кода

- `App` наследуется от `Application`.
- `App.OnStartup` вызывает `DbHelper.CreateDbAsync()`.
- `MainWindow` создает `MainViewModel` и задает его как `DataContext`.
- `MainViewModel` хранит `ObservableCollection<OrderWithCourier>`.
- `MainViewModel` создает команды `AddOrder`, `EditOrder`, `DeleteOrder`.
- `AddOrEditWindow` создает `AddEditViewModel`.
- `DbHelper` работает с PostgreSQL через `NpgsqlDataSource`.

## Схема зависимостей

```text
App
├── DbHelper.CreateDbAsync()
└── MainWindow
    └── MainViewModel
        ├── Orders: ObservableCollection<OrderWithCourier>
        ├── AddOrder: RelayCommand
        ├── EditOrder: RelayCommand
        ├── DeleteOrder: RelayCommand
        ├── DbHelper.GetOrders()
        ├── DbHelper.DeleteOrderByIdAsync()
        └── AddOrEditWindow
            └── AddEditViewModel
                ├── Order
                ├── SaveCommand
                └── DbHelper.AddOrderAsync() / DbHelper.EditOrderAsync()
```

## WPF

View-слой состоит из `MainWindow.xaml` и `AddOrEditWindow.xaml`. В XAML описаны элементы интерфейса: `ListView`, `GridView`, `ContextMenu`, `TextBox`, `ComboBox`, `Button`.

## MVVM

Фактически используются ViewModel-классы:

- [[Класс — MainViewModel]] — главное окно.
- [[Класс — AddEditViewModel]] — окно добавления и редактирования.

При этом MVVM не полностью чистый: кнопки в `AddOrEditWindow.xaml` используют обработчики `Click` в code-behind, а уже эти обработчики вызывают команды ViewModel.

## Data Binding

Главные привязки:

- `ItemsSource="{Binding Orders}"` — список заказов.
- `SelectedItem="{Binding SelectedOrder}"` — выбранный заказ.
- `Command="{Binding ...AddOrder}"` — команды контекстного меню.
- `Text="{Binding Address}"` — поля формы.
- `SelectedItem="{Binding Status}"` — статус заказа.

## `ICommand`

`RelayCommand` реализует `ICommand` и позволяет хранить действия в ViewModel. Это основной механизм команд в проекте.

## `async/await`

Методы работы с БД асинхронные:

- `CreateDbAsync()`.
- `GetOrders()`.
- `DeleteOrderByIdAsync()`.
- `AddOrderAsync()`.
- `EditOrderAsync()`.
- `LoadOrdersAsync()`.

## PostgreSQL, Npgsql, SQL

`DbHelper` содержит строку подключения, создает `NpgsqlDataSource`, маппит PostgreSQL enum `order_status` на C# enum `OrderStatus` и выполняет SQL-запросы.

## Что требует ручной проверки

- Корректность схемы таблиц.
- Заполнение таблицы `courier` начальными данными.
- Поведение `JOIN`, если у заказа нет курьера.
- Чистота MVVM.
- Ошибки привязок WPF во время выполнения.
