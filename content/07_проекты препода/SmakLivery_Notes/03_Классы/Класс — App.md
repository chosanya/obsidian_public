# Класс — App

## Исходный файл

`SmakLivery/App.xaml.cs`

## Назначение класса

`App` — класс WPF-приложения. Он отвечает за старт приложения и первичную инициализацию базы данных.

## Факты из кода

- Наследуется от `Application`.
- Переопределяет `OnStartup`.
- Вызывает `DbHelper.CreateDbAsync()`.
- При ошибке показывает `MessageBox` и завершает приложение через `Shutdown(1)`.

## Ключевой метод

```csharp
protected override async void OnStartup(StartupEventArgs e)
```

## Пояснение

Перед открытием основного окна приложение пытается подготовить базу данных: создать enum и таблицы.

## Что требует ручной проверки

- Метод использует `async void`.
- Если БД недоступна, приложение закрывается.
- Стартовое окно задано в [[App.xaml]], а инициализация БД находится в code-behind.
