# Класс — Order

## Исходный файл

`SmakLivery/Order.cs`

## Назначение класса

`Order` — базовая модель заказа.

## Факты из кода

Свойства:

- `Id` — идентификатор заказа.
- `Address` — адрес доставки.
- `Status` — статус заказа.
- `CourierId` — идентификатор курьера или `null`.

## Пояснение

`Order` используется в форме добавления и редактирования, а также передается в методы `DbHelper`.

## Что требует ручной проверки

- Класс не реализует `INotifyPropertyChanged`.
- Нет валидации адреса.
- `CourierId` есть в модели и форме, но при добавлении заказа не записывается в SQL `INSERT`.
