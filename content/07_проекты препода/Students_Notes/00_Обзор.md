# Students

## Что делает проект

`Students` — WPF-приложение для просмотра, редактирования, добавления, удаления и сохранения списка студентов.

Данные хранятся в файле `students.json`. Интерфейс показывает список студентов слева и данные выбранного студента справа.

## Основные технологии

- C#.
- .NET 10.0 Windows.
- WPF.
- XAML.
- MVVM.
- `INotifyPropertyChanged`.
- `ObservableCollection<T>`.
- `ICommand`.
- JSON через `System.Text.Json`.

## Архитектура

