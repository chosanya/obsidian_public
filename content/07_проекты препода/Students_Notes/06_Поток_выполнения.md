# Поток выполнения Students

## Общая схема

```text
App.xaml
→ MainWindow
→ DataContext = MainViewModel
→ чтение students.json
→ Binding в MainWindow.xaml
→ RelayCommand
→ изменение ObservableCollection
→ SaveAll / SaveOnExit
```

## Пошагово

1. WPF открывает `MainWindow`.
2. Окно создает `MainViewModel`.
3. `DataContext` получает ViewModel.
4. ViewModel пытается прочитать `students.json`.
5. `ListView` показывает `Students`.
6. При выборе студента обновляется `SelectedStudent`.
7. Правая часть окна редактирует свойства выбранного студента.
8. Кнопки вызывают команды ViewModel.
9. При закрытии окна вызывается `SaveOnExit`.

## Факт проверки

На текущей macOS-среде сборка завершилась ошибкой `NETSDK1100`, потому что проект таргетит `net10.0-windows`.
