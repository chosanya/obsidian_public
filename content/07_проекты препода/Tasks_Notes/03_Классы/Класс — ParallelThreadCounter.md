# Класс — ParallelThreadCounter

## Исходный файл

`TaskTest/ParallelThreadCounter.cs`

## Назначение класса

`ParallelThreadCounter` считает простые числа через ручное создание потоков.

## Поля

```csharp
private int _start;
private int _end;
```

## Метод `Start`

Создает потоки, каждый поток считает локальное количество простых чисел, затем общий результат обновляется внутри `lock`.

## Синхронизация

```csharp
lock (this)
{
    result += count;
}
```

Это защищает общий `result` от одновременной записи.

## Что сказать на экзамене

Класс показывает ручную многопоточность. В отличие от `Threads1`, здесь результат складывается безопаснее: каждый поток сначала считает локально, а потом добавляет итог под `lock`.
