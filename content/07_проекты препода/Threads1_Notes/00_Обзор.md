# Threads1

## Что делает проект

Проект сравнивает последовательное и параллельное суммирование чисел от `1` до `N`.

В коде есть:

- `SequentialSummator` — последовательное суммирование в одном потоке;
- `ParallelSummator` — суммирование через несколько объектов `Thread`;
- `Stopwatch` — измерение времени выполнения.

## Основные технологии

- C#.
- .NET 10.0.
- Консольное приложение.
- `Thread`.
- `Join`.
- `Stopwatch`.

## Архитектура

```text
Program.cs
→ SequentialSummator
→ ParallelSummator
```

```bash

```

## Что важно понять перед разбором

Параллельная версия делит сумму на 16 частей, но все потоки прибавляют данные к одному свойству `Result` без синхронизации. Это специально важное место для экзамена: так можно показать гонку данных.
