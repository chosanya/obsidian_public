# Структура проекта Threads1

## Карта проекта

Название проекта: `Threads1`

Назначение: демонстрация потоков и сравнение последовательного/параллельного вычисления.

Технологии: C#, .NET 10.0, консольное приложение.

Точка входа: `Threads1/Program.cs`.

Основные классы:

- [[Класс — SequentialSummator]]
- [[Класс — ParallelSummator]]

Архитектура: консольный запуск + два класса вычислителей.

Связанные темы экзамена:

- многопоточность;
- синхронизация потоков;
- гонка данных;
- измерение времени.
