# Проблемные места Threads1

## Гонка данных

В `ParallelSummator` несколько потоков одновременно выполняют:

```csharp
Result += i;
```

Это не атомарная операция. Результат может быть некорректным.

## Нет `lock`

Проект демонстрирует потоковую работу, но не защищает общий ресурс.

## Большое значение `N`

```csharp
var n = 2_000_000_000;
```

Выполнение может быть долгим.

## Предупреждение сборки

Сборка временной копии дает предупреждение `CS8622` по параметру `CalcPartSum(object k)`.

## Лишние `using`

В `ParallelSummator.cs` есть `using`, которые могут быть не нужны.
