# Экзаменационные билеты

## Билет 1

1. C#. Основы ООП. Создание классов и объектов.
2. Создать WPF-приложение с поддержкой MVVM для анимации движения квадрата по окружности при нажатии кнопки. Реализовать остановку анимации через повторное нажатие. Сохранять время запусков и остановок в БД. Использовать ICommand для обработки команд.

## Билет 10

1. Переопределение операторов.
2. Разработать WPF-приложение с MVVM для решения СЛАУ методом простой итерации. Сохранять промежуточные шаги вычислений в БД. Добавить отображение итераций. Вычислять количество итераций, проделанных для решения одной СЛАУ средствами SQL.

## Билет 12

1. Виртуальные методы и переопределенные методы.
2. Разработать WPF-приложение с MVVM для анимации изменения размера круга при наведении мыши с использованием асинхронной задачи. Сохранять время активности в БД. Использовать ICommand для управления.

## Билет 14

1. Работа с массивами.
2. Разработать WPF-приложение с MVVM для вычисления интеграла методом средних прямоугольников с параллельными вычислениями (используя Task). Сохранять пределы и результаты в БД. Реализовать визуализацию процесса.

## Билет 16

1. Стили в WPF.
2. Разработать WPF-приложение с MVVM для решения нелинейного уравнения методом половинного деления. Сохранять исходные данные и корень в БД. Реализовать ввод интервала пользователем.
